# session-startup — 起動時読込（読取りのみ）

セッション開始時に Notion「AI外部脳」から文脈を読み込み、前回からの連続性を確保する。
Notion MCP（`mcp__notion__*`、環境により `mcp__Notion__*`）を使う。**書き込みは一切しない。**

**コスト効率化A**: `notion-search` / `notion-fetch` は `max_highlight_length=0`・`page_size≤5` を既定にする。

## 手順

1. **`00_AI運用ルール`（`36d5952e-911b-815f-8f41-e789a5f6fac4`）** と **`Personal preferences保管ページ`（`36e5952e-911b-812a-8833-d79ce5ce7ad8`）** を `notion-fetch` で読む。
2. 今回の話題に関係する**プロジェクトを特定**する（`プロジェクト一覧`〔`a845eede-5289-4f5f-9f7f-3f1e7a75fcd0`〕。本リポは多くが PP-AI駆動開発 / AEP）。
3. 該当プロジェクトの `00_運用設計・背景` の**「現在地サマリー」セクションのみ**読む（全文は変更指示時のみ）。横断プロジェクトの「現在地サマリー」も読む。
4. **`セッションログ`〔`bb13106c-1f51-4a62-ad60-aa355bbe455b`〕を プロジェクト=該当 で絞り、最新3件（検討経緯・結論・次アクション）を読む**。特に直近の `次アクション` と `ステータス=進行中` を確認する。
5. 該当プロジェクトの **`Mistakes`〔`6e9433ff-bcff-4fe2-ba2e-3fe3fec2a0ca`〕** を読む。
6. 今回の論点キーワードで **`MASTER_KNOWLEDGE`〔`06ea50af-0d77-4ab2-8179-042f03c6a97a`〕・`Decisions`〔`0ac2817a-7101-4219-8537-e84414662e6f`〕** を検索し、ヒットした正本を読む（Decisions は矛盾照合準備）。
7. 過去資料に関わる／参照名で指された場合のみ `資料管理`〔`0d8605f9-a47c-4a37-bfae-1184ddda1b5f`〕を検索し Drive URL を fetch。
8. 迷ったら **`学び・ナレッジ所在マップ`〔`3965952e-911b-8109-83ae-d03a71d6e6d2`〕** を入口に保管先を特定する。

## 出力

読み込んだ内容を **3〜6行の「現在地サマリー」** としてユーザーに要約提示する（前回の結論／次アクション／進行中の論点／注意すべき Mistakes）。
**第6節（透明性）に従い、何を読んだかを必ず伝える。** 新しい主張が Decisions と矛盾する場合は、いつ・どのセッションで・なぜ決めたかを提示してから進める。
